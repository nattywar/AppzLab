📄 Example App Template

A starting point for your custom HTML applications

What is this?

This is a template HTML file that demonstrates how to create standalone HTML applications that can be hosted locally using AppzLab. No server required!

Features of this template:

  • Self-contained - all CSS and JavaScript included in one file
  • Responsive design that works on mobile and desktop
  • Modern, clean interface
  • Easy to customize and extend
  • No external dependencies needed

How to use this template:

  1. Copy this file and rename it (e.g., my-app.html)
  2. Edit the content, styles, and functionality
  3. Place it in the apps/ folder
  4. Refresh the AppzLab launcher to see your new app!
