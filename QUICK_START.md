# Quick Start Guide

## Welcome to AppzLab! 🚀

This guide will get you up and running in 60 seconds.

### Step 1: Open the Launcher
Simply **double-click** the `index.html` file in this folder. It will open in your default browser.

### Step 2: See Your Apps
You'll see a beautiful launcher page showing all available apps:
- Example App Template
- FDNY EMS Staffing System
- And any other HTML files you've added!

### Step 3: Add Your Own Apps
1. Copy any HTML file into the `apps/` folder
2. Refresh the browser page
3. Your app appears automatically!

---

## Installing to Home Screen

### On Mobile (iOS/Android):
1. Open `index.html` in Safari (iOS) or Chrome (Android)
2. Tap the **Share** button
3. Select **"Add to Home Screen"**
4. Done! Access AppzLab like a native app

### On Desktop (Chrome/Edge):
1. Open `index.html` in Chrome or Edge
2. Look for the **⊕ Install** icon in the address bar
3. Click it and confirm
4. Done! AppzLab is now in your apps menu

---

## Tips & Tricks

### ✅ Best Practices:
- Keep all your CSS and JavaScript inside the HTML file (self-contained)
- Use the example app template as a starting point
- Test your apps by opening them from the launcher

### 🎨 Customization:
- Edit `index.html` to change the launcher appearance
- Modify the app catalog to change names/descriptions
- Add your own branding and colors

### 📂 Organization:
- Main apps go in the `apps/` folder
- You can create subfolders for complex apps
- All HTML files will be detected automatically
